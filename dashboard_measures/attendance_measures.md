# Attendance measure reference

[Build the model](../guide/attendance_rebuild.md) · [Understand the figures](../guide/dashboard_metrics.md)

Use [the complete measure catalogue](attendance_rebuild_measures.md) to create the twenty measures and growing Attendance Bands table. Create them in the stated order and preserve their dependencies.

| Question | Main measures |
| --- | --- |
| How many meetings, visits and people? | Total Sessions, Total Attendance Records, Unique Attendees |
| How much time is recorded? | Average Attendance Minutes, Average Attendance Coverage %, Total Attendance Hours |
| Are people returning? | New Attendees, Returning Attendance Events, Repeat Participants, Repeat Participant Rate % |
| How often does each person attend? | Sessions Attended, People in Attendance Band |

Returning visits and repeat people count different things. Read the worked examples in [the metric handbook](../guide/dashboard_metrics.md) before selecting a percentage.
